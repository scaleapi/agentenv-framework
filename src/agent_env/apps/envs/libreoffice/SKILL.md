# LibreOffice on this computer

LibreOffice Writer (documents), Impress (presentations) and Calc (spreadsheets) are installed, with fonts that match
Office's (Carlito for Calibri, Caladea for Cambria, Liberation for Arial, Times New Roman and Courier New). It asks
nothing when it starts and keeps no lock files beside documents.

## Opening

- **A file:** double-click it in the file manager, for instance in Documents or Downloads. A .docx, .doc, .odt or .rtf
  opens in Writer; a .pptx, .ppt or .odp in Impress; an .xlsx, .xls, .ods or .csv in Calc. A CSV opens as
  comma-separated UTF-8, with no import dialog.
- **Something new:** Applications menu > Office > LibreOffice Writer, Impress or Calc. LibreOffice alone opens the Start
  Center, where Writer Document, Impress Presentation and Calc Spreadsheet each start a new file.

## Saving in Office formats

- **File > Save As** (Ctrl+Shift+S). Choose the type in the dialog's file type list, "Word 2007–365 (.docx)",
  "PowerPoint 2007–365 (.pptx)" or "Excel 2007–365 (.xlsx)", type the name, and press Save. It saves in that format
  without asking whether to keep it.
- **Ctrl+S** saves a file opened in an Office format in that format. A new file's first Ctrl+S opens Save As.
- Save into Documents unless you're told where.

## Writer

- Headings: the paragraph style box on the toolbar, or Ctrl+1 and Ctrl+2; body text is Ctrl+0.
- Bold, italic and underline: Ctrl+B, Ctrl+I, Ctrl+U. Lists: the bullet and numbering buttons on the toolbar.
- A table: Table > Insert Table (Ctrl+F12).

## Impress

- A new slide: Slide > New Slide (Ctrl+M). Its layout: the sidebar's Properties deck, Layouts.
- Click a placeholder to type its title or text.
- **An animation:** click the object to select it, open View > Animation, press the + button (Add Effect) and pick an
  effect, for instance Entrance > Appear or Fade In. A slide's transition is Slide > Slide Transition.
- The slideshow: F5; Esc leaves it.

## Calc

- Type in a cell and press Enter or Tab. A formula starts with =, for instance =SUM(B2:B10).
- Ctrl+Home goes to A1.

## When something's in the way

- A dialog waits for an answer; Esc closes most.
- A window you can't see is in the panel's window list at the top of the screen.
